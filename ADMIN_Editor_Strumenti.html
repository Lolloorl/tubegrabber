Editor strumenti TubeGrabber

Aggiungi o modifica le pagine extra dell'app, senza scrivere codice.

1 · Apri il tuo elenco attuale

Premi il pulsante e scegli il file docs\strumenti.json del tuo progetto. Se non ce l'hai ancora, salta questo passaggio.

2 · Compila lo strumento

Cosa deve fornire l'utente

Opzioni che l'utente può scegliere

Ogni opzione ha un codice (usalo nel comando scrivendolo tra graffe, es. {fmt}).

Il comando da eseguire

Segnaposto disponibili: {input} (file o link), {output} (file di uscita, per ffmpeg l'ultima riga deve essere {output}), {name} (nome del file senza estensione) e i codici delle tue opzioni.
Riga solo in certi casi: [fmt=mp3] -c:a (vale solo se l'opzione fmt è mp3). Per una casella sì/no usa true o false.

3 · Copia il risultato su GitHub

Qui sotto c'è l'elenco completo aggiornato.

  1. Su GitHub apri docs/strumenti.json e clicca la matita.
  2. Seleziona tutto (Ctrl+A), incolla (Ctrl+V) e clicca Commit changes.
  3. Gli utenti vedono lo strumento al prossimo avvio dell'app. Controlla in Impostazioni → Strumenti extra che non ci siano errori.
