# TubeGrabber

**TubeGrabber** è un'app per **Windows e Mac** che raccoglie in un unico posto diversi strumenti utili per video, audio, foto e QR Code.

By Lorenzo Orlandi

## 🛠️ Cosa puoi fare

- 📥 **Scarica da YouTube**: video (fino a 4K) o audio MP3, da singoli link o da intere playlist, anche con i sottotitoli.
- 🔄 **Converti file**: trasforma video, audio e immagini (MP4, MP3, WAV, MKV, PNG, JPG e altri). Puoi comprimere e ruotare i video e ridimensionare le foto.
- 🚁 **Drone Sync**: unisce e sincronizza i video del drone con le loro tracce audio.
- ◻️ **QR Studio**: QR Code personalizzati, anche per Wi-Fi, WhatsApp, e-mail e biglietto da visita, con link accorciabile.

## ⬇️ Come scaricarla

Vai alla pagina **[Releases](../../releases/latest)** e scarica il file adatto al tuo computer.

**Windows:** scarica il file `.exe` e aprilo. Se compare "PC protetto da Windows", clicca **Ulteriori informazioni** e poi **Esegui comunque**.

**Mac:** serve macOS 12 o successivo. Per scegliere il file giusto apri il menu Mela → **Informazioni su questo Mac**:
- se c'è scritto **Chip: Apple M…** scarica il file `mac-arm64.dmg`;
- se c'è scritto **Processore: Intel…** scarica il file `mac-x64.dmg`.

Apri il `.dmg` e trascina TubeGrabber in **Applicazioni**. Poi apri **Terminale** e incolla:

```
xattr -cr /Applications/TubeGrabber.app
```

Ora puoi aprire l'app normalmente.
